## Python 터미널 애니메이션

Python 3만 있으면 실행할 수 있습니다. 외부 패키지는 필요하지 않습니다.

```bash
python solar_system_ascii.py
```

- `Space`: 일시정지 / 재생
- `+` 또는 `-`: 공전 속도 조절
- `Q`: 종료
- `python solar_system_ascii.py --once`: 한 장면만 출력

행성 크기와 궤도는 시각화를 위한 표현이며 실제 비율과 다릅니다.
